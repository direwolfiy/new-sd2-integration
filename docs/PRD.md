# PRD — 漫剧生产平台

> 高保真前端原型，用于验证产品形态与交互流程。

---

## 一、产品定位

面向漫剧（漫改短剧）生产团队的一站式创作平台，覆盖从剧本创作到成片输出的完整链路，围绕seedance 2.0等主流视频生成模型。

**核心用户**: 制作人、编剧、分镜师、动画师、剪辑师
**核心价值**: 将散落在线下的漫剧生产流程收拢到一个平台，实现资产可追溯、协作有上下文、流程可管控。

---

## 三、模块详细设计

### 3.1 项目管理

#### 3.1.1 项目列表

**用途**: 用户登录后的默认着陆页，展示所有参与的项目。

| 字段 | 说明 |
|------|------|
| 项目名称 | 主标题 |
| 封面图 | 项目缩略图 |
| 状态 | 进行中 / 已完结 / 已归档 |
| 进度 | 整体完成百分比 |
| 最近编辑 | 时间 + 操作人 |
| 集数 | 已完成 / 总集数 |

**交互**:
- 卡片视图（默认）+ 列表视图切换
- 按状态筛选，按更新时间排序
- 点击卡片进入项目工作台
- 支持搜索项目名称

#### 3.1.2 项目创建 / 设置

**创建流程**:
1. 填写项目名称
2. 上传封面图（可选）
3. **选择风格预设**（必选，详见下方风格体系）
4. 确认创建

**风格预设会锁定以下全局参数**:
- 角色画风模板
- 场景美术模板
- UI 预览风格统一

> 风格预设一旦选定，后续更换不影响已有素材，但新创建的元素会默认使用新风格。

---

#### 风格体系

**风格选择机制**:

创作类型 × 题材类型 = 固定组合 → 映射到系统预设的风格库。用户只在前端选择组合，不直接接触风格参数。

```
创作类型（单选）        题材类型（单选）
  ┌──────────┐         ┌──────────┐
  │ 2D 动漫  │         │   古风   │
  │ 3D 动漫  │    ×    │   现代   │    →    系统风格库（后台预设）
  │  真人    │         │   科幻   │
  └──────────┘         │   仙侠   │
                       │   校园   │
                       │   悬疑   │
                       │   搞笑   │
                       └──────────┘
```

> 所有创作类型均为 AI 生成内容，区别仅在于画风。资产管理方式统一。风格库由后台维护，前端仅提供组合选择。

---

**项目设置**（创建后可修改）:
- 基本信息: 名称、封面、描述
- **风格预设**: 创作类型 + 题材（可切换，提示影响范围）
- 团队管理: 添加/移除成员、角色分配
- 参数配置: 画面比例、分辨率、帧率等

---

### 3.2 资产管理

#### 3.2.1 全局资产库

**用途**: 扁平的资源池，收拢所有项目生产过程中产出的图片、视频等原始素材。不做主体绑定（不按角色/场景等实体组织）。

**资产字段**:
| 字段 | 说明 |
|------|------|
| 缩略图 | 预览图 |
| 名称 | 自动生成或用户重命名 |
| 类型 | 图片 / 视频 / 音频 |
| 来源项目 | 标记产出来源 |
| 创建时间 | — |

**交互**:
- 网格浏览，按类型筛选、搜索
- 点击预览大图/播放
- 从全局资产库复制到项目元素库

---

### 3.3 项目工作台

> 项目工作台是用户进入项目后的主界面，顶部 Tab 导航切换子模块（总剧本、元素库、分集管理）。工坊作为项目级工具，不占用 Tab 位置，通过顶栏图标从项目或分集任意页面切换进入。项目设置放在顶栏右侧。进入分集后 Tab 消失，切换为分集工作台布局。

#### 3.3.1 总剧本

**用途**: 管理整部漫剧的总剧本（包含全部集数内容），侧重格式管控与拆集，而非逐字编辑。

**核心功能**:
- 文本编辑器（基础输入）
- 一键拆分集（将总剧本按预设模板和规则自动拆分到分集工作台）
- 版本历史管理
- 字数统计
- 角色标注与联动（关联项目元素库中的角色）

#### 3.3.2 工坊

**用途**: 灵活的创作空间，提供多种 AI 生成任务模式，跳脱于固定工作流之外。

**定位**: 项目级工具，不作为项目工作台 Tab 之一，而是通过项目/分集顶栏的工坊图标切换进入。在分集制作过程中可随时跳转使用，完成后返回原工作点。

**核心机制**:
- 模式切换: 轻量悬浮菜单，非固定侧栏分隔
- 生成界面: 根据选中模式动态切换参数面板和预览区
- 底部: 生成历史 / 迭代记录
- 生成结果可保存到项目元素库

#### 3.3.3 项目元素库

**用途**: 当前项目的结构化元素管理，角色、场景等实体在此组织。

**元素类型**:
- 角色（含表情/动作变体）
- 场景/背景
- 道具
- 音效/BGM

**与全局资产库的关系**:
- 全局资产库的原始素材可选取后组装为项目元素
- 项目中生成的素材自动沉淀到全局资产库

**交互**:
- 网格浏览，按类型 tab 切换
- 搜索、标签筛选
- 点击查看详情、编辑
- 引用到分镜中使用

#### 3.3.4 分集工作台

**用途**: 单集的完整生产流水线，从剧本到成片。

**分集创建方式**:
- 空白分集: 用户主动新建，直接进入该集工作台
- 从总剧本拆分: 引导跳转到总剧本模块，基于预设模板和规则自动拆分，批量生成各分集

新建分集时弹出选择，两条路径在一个入口汇合。

**子模块**:

##### 3.3.4.1 单集剧本
- 从总剧本拆分填充，或手动创建空白
- 独立可编辑

##### 3.3.4.2 分镜
- 基于单集剧本和项目元素（角色、场景）生成分镜卡片
- 每张卡片对应一个镜头，包含镜头描述（文本）、角色/场景引用
- 分镜图为可选参考，非必需；简单镜头可直接从文字描述生成视频
- 分镜图来源: AI 生成或用户上传
- 卡片视觉统一: 有图展示图片，无图展示镜头描述文字预览
- 所有生成结果支持手动编辑修改（文字、图片）
- 预留对话式修改入口（对单张或批量分镜对话调整）
- 支持排序，决定后续视频拼接顺序
- 生成机制不绑定特定方案，前端只定义输入（剧本+元素）和输出（分镜卡片）
- 生成过程支持可观测: 展示中间步骤、当前进度、预计耗时，告知用户是否可离开页面

**布局**: 内容区默认列表视图（每行展示镜头号、缩略图、描述文本、引用元素标签），文字信息优先；可切换为卡片网格视图。支持拖拽排序

##### 3.3.4.3 视频
- 基于分镜卡片 AI 生成视频片段
- 核心交互: prompt 编辑（支持预设模板）、@引用项目元素
- 支持切换为"生成分镜图"模式，为当前镜头补充参考图，生成结果自动回填到分镜卡片
- 每个视频片段对应一张分镜卡片
- 预览播放、多版本迭代

**布局**: 默认列表视图（同分镜页面风格），点击镜头进入生成详情页。详情页包含: 缩略镜头快速切换条 + 参考图预览区 + prompt 编辑 + 生成历史。列表视图支持"播放预览"，按顺序串播已生成的视频片段

##### 3.3.4.4 成片与导出
- 定位: 发布前的收口步骤，非专业剪辑
- 将视频片段按分镜顺序组合为完整单集
- 添加音效、BGM、字幕、转场
- 视频超分放大（导出前处理步骤，可选全片或指定片段）
- 导出成片（直接导出 / 导出到剪映等外部工具）

## 七、AI 生成任务交互规范

> 平台多个环节涉及长时 AI 生成任务（分镜、视频、工坊等），统一遵循以下规范。

**任务状态展示**:
- 展示当前阶段/步骤，非笼统的"生成中"
- 显示预计耗时和已用时间
- 明确告知用户是否可安全离开/关闭页面
- 支持查看中间产物（已完成的步骤结果）

**用户控制**:
- 支持取消进行中的任务
- 任务完成后通知提醒（站内通知，后续可扩展推送）
- 用户离开页面后任务不中断，回来可继续查看结果

**结果管理**:
- 生成完成自动展示结果
- 所有生成结果支持手动编辑修改
- 保留生成历史/多版本，可回溯
